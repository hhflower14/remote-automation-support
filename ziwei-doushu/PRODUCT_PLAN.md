## 0. 一句话结论

**别让 AI 从零“算命”，用开源数据集当底稿、AI 只负责“改写成好玩的话”。**
这个项目真正值钱的不是排盘代码，而是 Releases 里 **CC BY 4.0 可商用的 v4.0 解读数据集**：67.5 万张盘 × 13 个维度、已经是白话文、同一输入永远同一输出。拿它做底稿，报告质量稳定、成本低、不容易被 AI 胡编；但必须先把里面**不能商用的倪海厦原话**剥干净。

## 1. 项目实测结论（纠正原文案里的几处说法）

| 原文案说法 | 实际情况（已核对仓库 / 实跑） |
|---|---|
| 51.8 万张命盘 | 那是 v3.0 旧数据集（1924–1983，含约 2,520 条不存在的日期）。**现在有 v4.0：674,976 张盘（1950–2026，只含真实日期），13 维解读，压缩 161 MB / 解压 56.6 GB** |
| 1100 多条传统命理规则 | 是 `lib/ziwei/patterns.ts` **1100+ 行**格局规则库，不是 1100 条规则。实跑一张盘能识别出“紫微入命、三奇加会、魁钺同会”等格局 |
| 下载就能用 | 排盘引擎能直接用（`npm test` 全部回归通过，单盘约 70 ms）。但**仓库里的断语库是空的**（`db-analysis.ts` 是占位），AI 解读接口 `/api/interpret` 也没有。想要解读文字，只能用 Releases 数据集或自己写 |
| 古籍原文都整理好了 | 对。`lib/classics/` 里的《骨髓赋》《紫微斗数全集》《全书》属公有领域，可商用 |

**我做的实测**

- 下载 v4.0 的 1995 年分卷（2 MB 压缩 / 8,760 张盘），抽 600 张用当前引擎重新排盘：**命宫主星 600/600 一致**，说明“引擎排盘 + 数据集取文”可以对上（上线前应做全量或更大样本校验，README 写明引擎在持续更新，新版可能与数据集有差异）。
- 每张盘平均 **30,771 字**；其中每个维度开头的「XX 总览」白话段 + 「一句话定调」合计约 **3,720 字/盘**，这部分已经很接近小红书风格（例：“在人群里你不用刻意表现，坐在那儿就有人看过来……”）。
- 每张盘平均有 **44 处**「《天纪》pXX 时间码」引用，这些是倪师原话，**不能商用**，必须剥离（见第 2 节）。

## 3. 核心技术方案：数据集当底稿，AI 只做“翻译”

```
用户输入 (公历/农历生日 + 出生时间 + 性别)
   │
   ├─► 时间规整：调用引擎 chart-entry / true-solar-time / dst-cn
   │     得到 (公历日期, 时辰序号 0–11, 性别)
   │     注意：23:00–23:59 晚子时 → 次日、时辰 0
   │
   ├─► 引擎排盘 generateChart() + detectPatterns()
   │     → 画命盘、取命宫主星、格局标签（做视觉/关键词）
   │
   ├─► 数据集查表 key = YYYY-MM-DD-h-gender
   │     → 取已清洗的维度底稿（只取需要的维度）
   │     → 一致性校验：数据集 ms ≠ 引擎命宫主星 时，降级为“只用格局 + AI”
   │
   └─► AI 改写（按产品模板）
         输入：底稿 + 格局标签 + 产品题目
         输出：固定结构 JSON → 渲染成报告卡片/长图
```

### 3.1 为什么这样做

| | 纯 AI 生成 | 数据集底稿 + AI 改写（推荐） |
|---|---|---|
| 一致性 | 同一个人测两次可能不一样，用户截图对比就穿帮 | 底稿确定性，同输入同结论 |
| 质量 | 容易空话、编造星曜 | 有排盘依据，AI 只负责口吻 |
| 成本 | 输出长 | 输入约 3–6 千字、输出 1–2 千字，单份成本低；上线前用实际模型实算一次 |
| 速度 | 慢 | 可以**预生成热门组合 / 缓存**，同一 key 同一产品只生成一次 |

### 3.2 数据处理（一次性脚本）

1. 下载 v4.0 全部年份分卷，`zstd -d --long=27` 解压，校验 SHA256。
2. 逐行清洗：
   - 删除 `**关键推导**…`、`〔倪师断法…〕`、`——《天纪》…`、`〔词义〕…` 等段落；
   - 只保留产品要用的维度：`overview` `personality` `career` `wealth` `love` `friends` `move` `spirit`；
   - **不要入库 `health`**（含“睡眠和肠胃”“妇科保养”这类健康论断，有医疗宣传风险）、`parents` `children` `family`（作者自己也说六亲判断局限大，且容易引发负面情绪）。
3. 每个维度再拆成「总览白话」「一句话定调」「核心论断」三段，分别存，方便不同价位取用。
4. 存储：只存总览 + 定调大约每盘 3.7 千字，全量约 25 亿字；按行 zstd 压缩后放 SQLite / Postgres / 对象存储，按 key 读取。体量远小于 56.6 GB 原始数据。
5. 清洗后跑断言：全库不得出现“天纪”“倪师”“倪海厦”字样；抽查 1000 条人工过目。

### 3.3 AI 改写规则（prompt 要点）

- 只允许依据底稿和格局标签写，**不得新增星曜、宫位、年份事件**。
- 禁用词表：保证、注定、必然、一定发财、离婚、疾病、寿命、灾、血光、转运、改运、化解、招财、旺财、开运……
- 每段结尾给一个**可执行的小建议**（底稿本身就有，比如“每周挑一件小事故意按别人的办法做一次”），这是“娱乐 + 有用”的关键。
- 输出固定 JSON 结构（标题、3 个关键词、优势、雷区、一句金句、行动建议），前端渲染，不要让模型直接吐 HTML。
- 报告开头/结尾显式标注：“本报告由 AI 基于传统命理文化资料生成，仅供娱乐参考，不构成任何预测或建议”。

## 5. 小红书渠道：最大的风险在平台规则，不在技术

公开资料显示，小红书把**星座、运势、八字占卜、手相算命、测风水运势**等归为封建迷信相关内容：笔记推广这类服务属于违规情形，广告（含薯条加热）明确禁止投放；“转运、招财、逢凶化吉、旺财”等用语也在限制词里。关于店铺商品能否上架，没有找到明确的官方条款，**上架前必须查商家后台类目规则或直接问平台客服**。

因此调整原文案的打法：

1. **定位换说法**：不叫“算命 / 紫微斗数测试”，叫“传统文化性格测试”“古人视角的性格说明书”“出生时辰人格测试”。紫微斗数作为“文化背景”出现，而不是卖点。
2. **笔记不要直接挂“测命运”**：用“性格 / 天赋 / 职业倾向”切入；不要承诺预测未来；评论区不要用户报生辰（隐私 + 违规双重风险）。
3. **不投薯条 / 广告**：这类内容大概率审核不过，只靠自然流量。
4. **准备备用承接**：小红书只做内容和种草，交付入口准备好微信小程序 / H5 + 自有支付或其他平台，避免单平台封店就全部归零。
5. 先用 1–2 个号小规模试 2 周，记录限流、违规提示，再决定是否扩号。

## 6. 隐私与 AI 合规

| 项目 | 做法 |
|---|---|
| 最少收集 | 只要：出生日期、时辰（或时间）、性别。出生地只在需要真太阳时校正时可选填，**不要姓名、手机号、照片** |
| 最少保存 | 只存查表 key 和报告；原始出生时间不落库或 30 天内删除；报告链接用随机 token，不可遍历 |
| 告知 | 测试前一屏隐私说明 + 勾选同意；`app/privacy`、`app/terms` 改成自己的版本 |
| 未成年人 | 加年龄确认，不面向未满 14 周岁用户 |
| AI 标识 | 《人工智能生成合成内容标识办法》2025-09-01 起施行，AI 生成的报告要有**用户一眼能看到的显式标识**（开头或结尾文字说明），分享卡片上也要带 |
| 模型选择 | 面向境内公众提供生成式 AI 服务，优先使用已完成备案的大模型 API，并保留调用记录 |
| 网站 | 境内服务器需 ICP 备案；站内直接收款前确认是否需要经营性许可，拿不准就把收款放在平台侧 |

## 7. 里程碑（MVP 约 2 周）

| 阶段 | 时间 | 交付 |
|---|---|---|
| M0 合规确认 | 第 1–2 天 | 小红书商家类目确认；产品命名、免责声明、隐私说明定稿 |
| M1 数据管线 | 第 2–5 天 | v4.0 全量下载 → 清洗（剥倪师原话、去健康/六亲）→ 入库；全量清洗断言通过；引擎 vs 数据集一致性全量校验 |
| M2 报告生成 | 第 4–8 天 | 3 个主推题目的 prompt + JSON 模板；禁用词过滤；同 key 缓存；20 张盘人工评审 |
| M3 网页改造 | 第 6–10 天 | 在 Codex 网页基础上：手机端一屏表单 → 免费卡片 → 付费解锁报告 → 分享长图 |
| M4 小规模上线 | 第 11–14 天 | 1–2 个账号、每天 2–3 篇笔记；记录曝光、点击、转化、退款、违规提示 |
| M5 复制 | 之后 | 同一套“表单 → 底稿 → AI 改写 → 卡片”框架，换数据源做 MBTI / 职业性格 / 城市适配等 |

**要盯的指标**：笔记 → 主页点击率、免费卡片完成率、免费 → 付费转化率、单份 AI 成本、退款/投诉率、笔记违规数。

## 8. 风险清单

| 风险 | 等级 | 应对 |
|---|---|---|
| 小红书判定“封建迷信”限流 / 下架 / 封店 | 高 | 文化 + 性格定位；不投广告；备用交付渠道 |
| 不小心卖了倪师原话（NC 协议） | 高 | 入库前清洗 + 全库断言 + 输出侧二次过滤 |
| AI 胡编、写出疾病 / 灾祸 / 离婚结论 | 中 | 只给底稿；禁用词过滤；健康和六亲维度不入库 |
| 引擎更新后与数据集不一致 | 中 | 锁定引擎版本（打 tag）；上线前全量比对；不一致时降级 |
| 1950 年前 / 2026 年后出生不在数据集 | 低 | 前端限制年份或降级为“格局 + AI”简版 |
| 同质化竞争 | 中 | 卡片设计、题目包装、可执行建议是差异点；作者线上站 ouranic.cn 免费，需靠“好玩 + 好分享”而不是“更准” |
